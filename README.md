# AgroConecta - Backend (API)

Servidor backend da aplicação AgroConecta, responsável pela lógica de negócios, autenticação, gerenciamento de banco de dados e comunicação em tempo real.

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias principais:

* **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
* **Runtime:** [Node.js](https://nodejs.org/)
* **Framework Web:** [Express](https://expressjs.com/)
* **ORM (Banco de Dados):** [Prisma](https://www.prisma.io/)
* **Banco de Dados:** PostgreSQL
* **Comunicação Real-time:** [Socket.io](https://socket.io/) (para o chat)
* **Autenticação:** JWT (JSON Web Token) e BcryptJS
* **Upload de Arquivos:** Multer
* **Logs:** Winston

## 🚀 Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:

* [Node.js](https://nodejs.org/) (Versão LTS recomendada)
* Gerenciador de pacotes (`npm` ou `pnpm`).

## 📦 Instalação

1.  Acesse a pasta do projeto no terminal.
2.  Instale as dependências do projeto:
    ```bash
    npm install
    ```

▶️ Execução
Para rodar o servidor em modo de desenvolvimento (com reinicialização automática):

 ```bash
    npm run dev
    ```
